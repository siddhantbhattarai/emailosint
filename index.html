traceosint

Multi-vector identity reconnaissance for investigators — email, online accounts, phone numbers and location artefacts, each result carrying an explicit confidence.

Install via apt View on GitHub →

Install — Debian / Ubuntu

# add the signing key and repository
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://siddhantbhattarai.github.io/traceosint/pubkey.gpg \
  | sudo tee /etc/apt/keyrings/traceosint.asc > /dev/null

echo "deb [signed-by=/etc/apt/keyrings/traceosint.asc] https://siddhantbhattarai.github.io/traceosint stable main" \
  | sudo tee /etc/apt/sources.list.d/traceosint.list

sudo apt update
sudo apt install traceosint

Updates then arrive through apt upgrade like any other package. The repository metadata is GPG-signed; apt verifies every download against the key above.

Capabilities

Mail infrastructure

MX, SPF, DKIM, DMARC, DNSSEC, MTA-STS, BIMI, SMTP RCPT + catch-all, disposable/role/free classification.

Account-existence oracles

Is this email on Facebook, Instagram, Twitter/X, Pinterest, GitHub or Bitbucket? Signup-validation technique — sends no mail to the target.

700+ site enumeration

WhatsMyName-driven, strict two-sided matching, 0% measured false-positive rate, honest coverage accounting.

Phone intelligence

Validity, country + region, line type (mobile / fixed-line / VoIP …) and canonical E.164 / national formats.

Location intelligence

IP geolocation with ISP/ASN and proxy/hosting flags; EXIF GPS + capture device and time from a shared photo.

Breach membership

Have I Been Pwned metadata across ~1000 services — the strongest "where registered" signal, no raw dumps.

Use

# email: infrastructure, identity, breaches, 700+ sites + account oracles
traceosint scan target@example.com

# phone: validity, country/region, line type
traceosint phone +14155552671
traceosint phone 9812345678 --region NP

# IP geolocation and photo EXIF GPS
traceosint ip 203.0.113.9
traceosint exif ./evidence/photo.jpg

# machine-readable output for pipelines
traceosint scan target@example.com -f json > report.json

Confidence legend

[+]confirmed — verified true
[~]likely — strong signal, not proof
[-]absent — verified false
[?]inconclusive — blocked/ambiguous, not evidence of absence

Reliability & ethics

Reliability. Account oracles are as accurate as the IP they run from. Meta and Pinterest rate-limit per egress IP — from a datacenter address those answer inconclusive, never a false negative. Route through a clean residential proxy with TRACEOSINT_PROXY for reliable Instagram/Facebook results.
On location. traceosint does not and cannot track a person's live location from an email or phone number — no lawful technique does. It provides location intelligence about artefacts you already lawfully hold (an IP, a photo's EXIF). For authorised investigations only; respect GDPR/CCPA and platform terms.
